Sekai Privacy Notice

This notice describes the behavior found in the current Sekai 1.1.0 package source. An application that embeds Sekai controls its own data sources, storage, networking, and permissions and must describe those practices separately.

Last updated: August 20, 2026

OFFLINE CORE

Core Sekai renders from a bundled Natural Earth atlas. It does not require a network connection, account, API key, MapKit configuration, JavaScript, WebView, or location permission.

The current package includes no advertising, analytics, tracking, telemetry, cloud-sync, or crash-report upload integration. Core Sekai does not send atlas use, camera movement, layer content, or interaction data to Kaizōsha.

HOST-PROVIDED DATA

A host application can provide annotations, routes, shapes, heat points, GeoJSON, and other layer values. Sekai processes these values within the host application and does not fetch or upload them itself.

The host application may independently download, store, sync, or share its own data. Those choices belong to the host application and are outside Sekai's runtime behavior.

OPTIONAL LOCATION MODULE

SekaiKit does not link Core Location. Location support is provided by a separate optional SekaiLocation product that a host application must explicitly add.

The host supplies the platform usage description, requests when-in-use authorization, and controls when location updates start and stop. The module exposes the received coordinate and horizontal accuracy to that host and can turn the coordinate into a globe annotation. The host remains responsible for any later persistence, networking, or sharing of location data.

STATE AND PERSISTENCE

Sekai exposes camera, style, feature, filter, and layer values to the host application. Some suitable values support Codable so the host may choose to persist them.

Sekai itself does not create a user account, analytics record, cloud profile, or application database. Any persistence added by the host application is governed by that application's privacy notice.

INSTALLATION AND EXTERNAL SERVICES

Adding Sekai through Xcode or Swift Package Manager requires those tools to retrieve the public package from GitHub. That installation traffic is handled by Apple, GitHub, and the user's network configuration, not by the Sekai runtime.

Links opened from this product website are handled by the destination website and browser.

GEOGRAPHIC DATA LIMITS

The bundled Natural Earth-derived data is intended for visualization. Do not use it for navigation, surveying, legal-boundary determination, emergency decisions, or precision GIS work.

Country aggregation, map units, and political-worldview classifications follow the bundled source and Sekai's documented filters. A host application is responsible for selecting and explaining any interpretation it presents to users.

PRODUCT WEBSITE

This notice covers the Sekai package, not visits to sekai.kaizosha.org or kaizosha.org. Website visits are governed by the Kaizōsha website privacy policy.

CHANGES AND CONTACT

If Sekai's package behavior changes, this notice will be updated to describe the changed release.

Questions about Sekai privacy can be sent through the Kaizōsha contact page. Suspected security issues should follow the repository's security policy.
